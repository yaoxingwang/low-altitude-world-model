低空世界模型：关键问题与验证路线

深化版 · 方法保持载体通用，示范验证明确适用范围

低空观测并不完整，动作会改变未来，动力学模型也存在误差。

核心问题：如何在这些条件下构建足以支持可靠决策的世界模型？

研究主线：保留决策信息 → 预测动作后果 → 识别模型失效 → 验证安全泛化。

B

第一项：面向可通行性与交互决策的场景表征

关键问题：同样“看起来没有障碍”，能否真的安全通过？

楼宇转角后的空间可能尚未观测；窄通道是否可通行取决于机体尺寸和跟踪误差。动态主体的位置相同，运动方向不同也会改变避让决策。仅改善渲染质量无法回答这些问题。

建议提纲：

  • 构建几何—语义—运动联合表征，关联静态边界、动态主体与相对运动。
  • 区分已知自由空间、已占用空间和未观测空间，避免把不可见区域当作安全区域。
  • 用观测历史维护状态估计，显式记录定位、深度和主体运动的不确定性。
  • 将载体尺寸、机动约束和安全裕量接入可通行性判断。

模块输出： 局部场景状态、空间约束、动态主体历史、自机状态估计与置信度。场景图、占据场或 3DGS 可作为载体，具体形式由决策需求决定。

可检验假设 H1： 在相同感知输入与计算预算下，加入历史和未知空间建模能够降低危险通道的误判。

验证： 先比较深度、位姿、占据和可通行性误差，再固定规划器比较碰撞和任务失败。真实数据缺少可通行标签时，先用带几何真值的合成场景构建标签。

必要对照： 单帧表征、无未知空间处理、无运动历史，以及完整表征。不能只用 PSNR 或新视角合成效果证明对决策有效。

衔接： 第二项在该状态空间中推演未来；第三项以它作为当前可知信息，不能额外读取测试场景真值。

C

第二项：动作条件下的可信演化与可控生成

关键问题：模型学到的是“画面怎么变”，还是“动作为什么导致不同结果”？

相机移动会造成画面变化，但这不等于学会飞行动力学。历史轨迹只提供一个已执行动作的结果，无法直接监督所有候选动作。长时序推演还会遇到误差累积和脱离训练分布。

建议将世界模型拆成三个相互约束的部分：

部分 要建模什么 数据要求
状态转移 自机响应、主体运动、交互和扰动影响 带时间戳的状态—动作—后继状态
观测生成 新状态和新视点下会看到什么 图像、几何、位姿与传感器模型
场景配置生成 布局、初始状态、主体策略和环境条件 可编辑场景资产、参数与可行性约束

建议提纲：

  • 采用名义动力学与学习残差结合的演化模型，保留载体和控制器条件。
  • 先统一动作接口：参考轨迹通过对应控制器执行，并同时记录指令和实际响应。
  • 用仿真分支试验补充动作覆盖，检验换一个动作后的未来是否预测正确。
  • 维护对象身份、几何边界和运动约束，并按预测跨度评价长期误差。
  • 生成可执行场景，联合约束物理可行性、场景覆盖和任务难度。

危险场景还应检查任务是否可完成。无法通过的场景单独统计，避免用不可解任务制造虚假的算法失败。

可检验假设 H2： 相比仅拟合日志或纯视觉生成，动作条件和动力学约束能改善候选动作后果的排序。

物理耦合的范围需要具体化： 先研究“地形与障碍 → 风扰动 → 载体响应 → 传感观测”的作用链。几何改变碰撞边界与遮挡，风影响跟踪，光照与能见度影响观测。

这一阶段覆盖环境—动力学—观测的部分耦合。旋翼下洗、热流与瞬态湍流需要额外模型和数据，不能由简单阵风参数替代。

风场处理： 风不可直接观测时作为有界扰动或隐变量。WindSeer 可支持时间平均风场研究，阵风时序另作假设并独立验证。

长时序验证： 分别报告连续推演误差，以及接收新观测后的任务表现。长任务成功不能直接证明长跨度预测准确。

衔接： 向第三项提供未来状态及置信度；向第四项提供场景配置与可响应自机的主体策略。两条输出应共享场景语义和约束。

D

第三项：模型误差约束下的预测—规划耦合

关键问题：世界模型预测不准时，规划器如何避免选中“虚假的最优动作”？

候选动作越激进，越可能离开训练数据覆盖的范围。即使平均预测误差较小，只要在狭窄通道或交会时刻低估风险，规划就可能失败。

建议提纲：

  • 生成满足载体机动约束的候选参考轨迹，并推演其他主体的响应。
  • 同时评价任务收益、约束违反和模型不确定性，关注高损失结果。
  • 根据可信程度调整预测跨度、风险裕量和重规划频率。
  • 执行短段动作后用新观测纠正状态；低置信度时采用载体适用的保守策略。

悬停并非所有载体都可执行。保守策略可能是减速、增大间隔、改道或保持可行航路，需由载体能力限定。

交互必须分级验证：

等级 场景中的其他主体 能证明什么
静态障碍 不运动 基础避障与约束规划
动态障碍 按预设轨迹运动，不响应自机 运动预测与动态避障
响应式主体 根据自机动作改变行为 预测—规划耦合的交互价值

可检验假设 H3： 在响应式主体和模型偏差下，耦合决策比固定预测、一次规划具有更好的安全—效率权衡。

关键试验：同一起点，多种动作。 固定初始状态、环境与外生随机种子，分别执行不同动作。其他主体使用相同响应策略，但允许因自机行为不同而改变轨迹。

比较预测风险排序与实际风险排序，再计算所选动作相对候选集中最佳动作的损失。通过重复试验处理随机性；仿真分支只能证明所设仿真中的动作后果。

置信度需要校准，并检查其是否能识别高误差样本。未经校准的网络分数不能直接解释为碰撞概率或安全保证。

必要对照： 恒速预测＋滚动规划、学习预测＋单向规划、耦合推演、耦合推演＋置信度处理。保持候选动作数、约束和计算预算一致。

E

第四项：区分模型有效性与仿真偏差的验证体系

关键问题：系统是在世界模型里表现好，还是在独立执行环境中也有效？

验证层次 检验内容 证据边界
离线回放 状态估计、几何、已发生轨迹的预测 不能直接评价未执行动作的后果
可重复交互试验 候选动作分支、避碰、任务成功、约束违反 结论首先适用于指定仿真和主体策略
模型偏差测试 质量、延迟、跟踪误差、传感噪声与风扰动变化 参数变化不能代替跨载体家族验证
真实数据校核与实飞 真实响应、真实观测误差和任务表现 仅对所测载体与工况形成直接证据

评价模型与被测模型分离。 世界模型负责预测，独立物理推进器负责执行和计分。测试时固定模型，不用同一批测试失败案例更新后再报告原测试结果。

数据划分按场景组织。 划分城市或地图、完整轨迹、动态主体策略、风场地形和载体配置，避免相邻帧随机划分造成泄漏。

泛化单独报告： 已知场景内的新轨迹、未见地图、未见交互策略、未见扰动，以及未见载体模型。只有单类多旋翼实验时，结论应写为多旋翼示范。

两个容易误判的地方：

  • FlightBench 与 AvoidBench 都使用 Flightmare 相关组件；换平台名称不自动获得独立物理验证。
  • 对抗生成的危险场景能测试弱点，但其失败率不能直接解释成真实运行事故概率。

模型指标： 可通行性误判、分跨度预测误差、风险排序一致性和置信度校准。

系统指标： 任务成功率、碰撞率、最小间隔、约束违反和计算延迟。

失败归因： 依次检查观测错误、状态表征遗漏、演化预测错误、风险评价错误和控制跟踪失败。只统计碰撞次数无法指导四部分分别改进。

逐时刻记录： 时间戳、坐标系、观测、估计状态、真值状态、指令动作与实际响应。

逐场景记录： 控制器版本、载体参数、主体策略及随机种子。

估计状态用于模拟实际可用输入，真值状态用于监督或计分。两者必须区分，避免用仿真真值替代实际感知而高估性能。

分支试验要能复现整个状态。 恢复时除位置和速度，还应恢复控制器内部状态、主体行为状态与随机数状态。只有起点相同不足以保证公平。

评价协议： 各方法使用相同初始条件、动作候选预算和时延约束。对重复试验报告配对差异与置信区间，并按场景难度和失败类型拆分结果。

实施依赖： FlightBench 和 AvoidBench 的文档采用 Ubuntu、ROS 与 NVIDIA 渲染环境。本次未安装、未运行，不把仓库可访问等同于平台已复现。

跨载体承诺边界： 方法层预留载体条件接口；示范层先选可复现载体。声称跨载体家族泛化前，应补充另一类动力学与控制模型的验证。

H

可写入提纲的深化表述与文献依据

第一项：面向低空通行与交互决策的场景状态表征。 研究不完整观测下几何、语义与运动信息的统一表示。关联未知空间、主体交互与载体机动约束，形成支撑可通行性判断的场景状态。

第二项：动作条件与物理约束驱动的世界模型及可控场景生成。 研究环境扰动、载体响应和观测变化的关联建模。建立物理模型与学习残差结合的演化机制，控制长时序误差，并生成可执行、可交互的测试场景。

第三项：模型不确定性约束下的预测—规划耦合决策。 研究候选动作与主体响应的联合推演。结合预测置信度调整规划跨度和风险裕量，形成能够通过新观测持续纠正的动作生成机制。

第四项：面向模型偏差与分布变化的虚实融合验证。 建立公开数据回放、仿真分支试验和真实数据校核相结合的验证体系。评价方法在未见场景、交互策略和载体条件下的有效性，明确示范结论的适用范围。
